# Gesture-Based Volume Control System
This project is a Python-based **Gesture Volume Controller** that uses your webcam and hand gestures to dynamically control the system volume. It utilizes real-time hand tracking to detect the distance between your thumb and index finger and adjusts the volume accordingly.

## Features

- Real-time hand tracking using webcam.
- Controls system volume using hand gestures (distance between thumb and index finger).
- Displays visual feedback for volume level and finger distance.
- Frame rate (FPS) display for performance monitoring.
- Intuitive volume bar and percentage display.
- Color feedback when volume reaches minimum level.

## Tech Stack

- Python
- OpenCV
- MediaPipe
- NumPy
- datetime
- Pycaw (Python Core Audio Windows Library)
- comtypes
